# UX specification (V1)

## Product feel

Modern physical audio device — not a DAW, not Voicemeeter Potato, not a control panel.

Visual: minimal, dark, clean, precise, calm, high contrast where needed, icon-first, subtle depth, excellent spacing/typography, beautiful meters.

## Home screen

- Brand mark `MB`
- Source tiles (instrument / app / mic) with live meters
- FX affordance per source
- Master meter
- Monitor + broadcast destinations
- Single Start control

Advanced controls appear only when a tile is expanded.

## Source picker (`+`)

Visual sections: physical inputs, applications, system audio, plugins, media files. Recently used first. Search only when useful.

## Accessibility

Every icon control: accessible name, keyboard focus, screen-reader label, hover + focus tooltip.

## Non-goals for V1

Accounts, cloud, social, marketplace, mobile, macOS/Linux UI parity.
